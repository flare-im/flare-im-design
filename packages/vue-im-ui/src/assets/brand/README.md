# Authentication Brand Artwork

`auth-technology.webp` is the shared desktop authentication illustration.
Generated with the built-in image generation tool on 2026-09-11, then resized
to 1152x768 and encoded as WebP with the alpha channel preserved. The original
generation is retained at the tool's generated-image location; no remote asset
service is required at runtime. Keep brand artwork in the published package;
only emoji/sticker raster packs are excluded by the package file rules.

## Generation Prompt

Use case: stylized-concept. Create a premium technology brand illustration to
fill the left half of a Flare IM desktop sign-in page. The existing page uses
violet #6d28d9, off-white/lavender neutral surfaces, and clean restrained
typography. Subject: a precision-engineered optical interconnect sculpture, made
from three layered frosted-glass rectangular planes threaded by one continuous
violet anodized-metal ribbon, with a few fine etched circuit traces and tiny
rectangular connection ports. This is an abstract brand object, not an actual
device or a logo. Clearly defined translucent edges, subtle silver details and
a small cool-cyan reflection provide material contrast. Refined, architectural,
tactile 3D product-render aesthetic, not cartoon or generic sci-fi. A single
coherent object in a three-quarter isometric view, fully visible, centered,
occupies about 80 percent of a landscape 3:2 canvas. True transparent alpha
background; soft contact shadow only, no floor rectangle or vignette, so it
integrates on both light and charcoal interfaces. No text, no letters, no
numbers, no logo, no UI, no chat bubbles, no screen mockup, no charts, no spheres
or orbs, no floating dots, no bokeh, no neon aura, no radial gradient backdrop,
no frame, no watermark. Detailed enough to be handsome at 480-560 CSS pixels
wide, with clean silhouette and generous edge clearance. Return a
production-ready PNG cutout with genuine transparency.
