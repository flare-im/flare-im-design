# GroupCallView

<p><span class="flare-tag">Call</span></p>

> Group (multi-party) call — a participant grid whose column count adapts to headcount, speaking highlight, mute / camera-off badges, and an add-member control. Each tile's video is injected by the host via the `#tile="{ participant }"` slot.
