# Examples

These are small consumer applications, not alternate galleries or product shells.

| Platform | Path | Purpose |
|---|---|---|
| Vue | `vue/` | Vite app using only the published Vue package surface |
| Flutter | `flutter/` | Flutter app using the local `flare_im_ui` package |
| Compose | `compose/` | Android app consuming the Compose library as a Gradle project |
| SwiftUI | `swiftui/` | XcodeGen app consuming the self-contained Swift package |

The shared component and theme scenario manifest lives in `gallery/` and drives
documentation and visual checks. It is data, not another application.
