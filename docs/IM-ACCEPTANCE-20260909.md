# 组件系统验收记录（2026-09-09）

## 已交付范围

当前目录为 **135 个组件 / 11 类**，能力矩阵覆盖 14 个 IM 场景。ConfigProvider 是 Vue 专属入口；组件数量不等于四端端到端覆盖率。

- 四端场景组件：MemberPanel、DeviceSessions、MediaCenter、NotificationPreferences、DangerConfirm、CapabilityBoundary、CallDevicePicker。
- 四端传输队列、搜索组合、历史分页/阅读锚点、通话失败/恢复和窄屏控件；语义与逻辑尺寸统一，系统字体和 emoji 允许平台差异。
- 共享适配：搜索响应所有权、媒体签名 URL 重新解析、受限且可取消的消息定位。
- 实际 Web/Tauri 页面已接入定位、搜索状态保护、危险确认。实际页面存在独立组合，不能只修改共享页面就认为示例生效；此次通过真实点击发现并补齐。
- core SDK 的 iOS FFI 构建固定最低 iOS15，并检查 archive 中每个对象，拒绝混入要求更高系统的产物。三架构重建、iOS/Flutter 同步完成。

## 尚未完成的完整规划验收

- P0：受控弱网反复恢复、真实长历史 ACK/撤回/编辑和草稿切换全端矩阵；Flutter Android/iOS 真实收发与系统键盘生命周期。
- P1：时间范围检索、成员角色变更、远程设备撤销及系统通知权限的真实后端组合；原生多选/转发受限的完整操作矩阵。
- P2：RTC 插件的真实媒体、屏幕共享、设备拔插与弱网。IM 服务地址本身不能证明这些插件已部署。
- 物理设备：旧版 iOS、不同 Android 厂商、系统大字号、读屏、安全区、折叠/分屏。现有模拟器与浏览器测试不能替代这些验收。

因此本轮交付不是“完整规划已经全部验收完成”。上述项保留在规划中，不用空壳组件或构建成功替代真实业务证据。本轮未发布 npm/Maven/SPM 新版本，也未部署本轮新代码到服务器。
