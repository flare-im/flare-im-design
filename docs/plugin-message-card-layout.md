# Vue 插件消息卡片：文字操作布局

范围：Web Vue 共享 `FlarePluginView`，接龙、任务、投票、日程、公告，以及同一协议的其他插件。真实聊天通过 Core 的 `PluginMessage` 直接复用，无应用私有样式。Flutter、SwiftUI、Compose 尚未同步此视觉方案。

## 层级与布局

- 类型：12px 次级文字；真正的消息标题：15px 半粗；正文14px，辅助信息12–13px。沿用现有 tokens。
- 卡片使用单层边框，移除消息卡片自身的阴影。长标题自然换行，名单、进度、时间仍按协议顺序呈现。
- 操作使用共享 `FlareButton appearance="text"`：主操作为品牌色半粗文字，危险操作为红色文字，辅助操作与详情为中性色。动作名称明确表达作用，不能只靠颜色辨别。
- 有操作的卡片：操作与详情同处紧凑底栏；按钮按内容宽度排列，空间不足自然换行。
- 只有详情的卡片：详情移到标题栏右侧，不产生空底栏。
- 文字操作仍保留最小命中区、可见焦点、loading、disabled，以及危险操作确认。最终确认面板保持明确的危险按钮。
- 多选投票的提交动作采用同样的文字样式；投票选项仍是可交互的选项行，选中、数量、比例不退化成普通链接。
- 详情继续复用自适应面板，加入明确的关闭入口；支持 Escape、平台返回、焦点回到触发入口。嵌入视图沿用更舒适的内容字号，动作仍为文字样式。

## 预览

组件预览：`examples/vue/plugin-cards.html`。全部为明确标记的虚构示例数据，不调用 SDK、网络或消息命令。可验证参与接龙、表单、任务完成、投票、日程回应、公告确认，以及模拟失败后重试、已结束、不可用、深浅主题。移动端保留横向消息类型筛选。

```sh
cd examples/vue
npm run dev -- --host 127.0.0.1 --port 5298
```

打开 `http://127.0.0.1:5298/plugin-cards.html`。

320/375px 容器工具使用同一套编译后 JS/CSS，仅在本机测试 HTML 中限制根容器宽度，不向应用注入业务状态。它验证容器自适应；不等同于实体手机浏览器、触摸输入或完整移动浏览器视口验收。

相关组件测试、Vue 类型检查、SFC 编译和真实聊天验证结果参见该目录的 `report.md`。操作的 ID、权限、表单、确认文案、乐观状态和 SDK 调用契约保持原样。真实聊天回归只读已有实验消息并打开/关闭详情；交互修改仅发生在明确标记的本地组件示例中。
