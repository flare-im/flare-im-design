# 插件消息卡片的文字操作

Web Vue、Flutter、SwiftUI 和 Compose 的通用 PluginView 使用同一层级：类型为次要信息，正文为主要内容，进度和结构化字段保持各自语义。接龙、任务、投票、日程和公告复用这一组件，不在应用内重画操作按钮。

- 默认使用小尺寸的 text 外观，主操作为品牌文字色，危险操作为危险文字色，其余为次要文字色。按钮文案保留动作含义，不只依赖颜色。
- 悬停和键盘焦点没有文字下划线或常驻描边；键盘焦点使用轻微语义底色。系统高对比度和原生无障碍焦点提示保留。
- 触屏的文字按钮至少保留 48 的实际点击区域；文字可换行，操作之间不重叠。
- 有底部操作时，详情与操作放在相邻的可换行区域，详情靠尾侧；没有底部操作时，详情收进标题行。entries 已有“查看全部”时不重复增加详情入口。
- 卡片使用次要边框的 60% 不透明度，不加阴影；详情和操作之间保留内容分隔线。
- 不可用、只读、加载、确认、表单、错误恢复和原始 action/row/page 参数仍由原有通用组件及宿主处理。外观不改变业务状态与协议。

Flutter 通过 OverflowBar + Wrap 组合操作区域；SwiftUI 通过共享 FlowLayout 在有限宽度中换行；Compose 通过本地 UI 布局测量每个按钮后换行。三者保留平台的文字缩放和键盘/读屏语义。钱包沿用账户外观，通用文字按钮也继承同一样式。

这项改动不涉及 SDK、服务端、FFI 或金额规则。
