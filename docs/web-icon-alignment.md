# Web 图标尺寸、描边与对齐

Web 产品界面采用 `FlareIcon` / `FlareGlyph` 与共享控件组合，应用不覆盖组件内部 SVG。
`FlareIcon.size` 和 `FlareGlyph.size` 支持 `sm` / `md` / `lg` / `xl`，数字尺寸用于媒体覆盖层。

| 用途 | 尺寸 |
| --- | --- |
| 列表状态、尾部箭头、紧凑操作条 | `sm` · 16px |
| 页头、设置行前导图标、输入工具、常规菜单 | `md` · 20px |
| 底部导航、主要图形操作 | `lg` · 24px |
| 空态、错误态、上传占位 | `xl` · 32px |

`FlareIconButton` 的三档图标为 16 / 20 / 24px。自定义按钮边长按原比例选择最近的一档
标准图标尺寸，最小 16px；按钮边长及触控命中区域独立于图标尺寸。
`FlareButton` 的前导图标也按三档尺寸使用 16 / 20 / 24px。

具名与自定义菜单图标使用同一个渲染入口并继承图标列尺寸。设置行的前导容器和图形均为
20px，尾部箭头为 16px；不再用 CSS 将 18px 容器内的图形单独扩大。

线性图标使用现有 Lucide / kit 注册表的 24 单位画布与 1.75 描边，继承语义颜色。
消息已读、失败、发送和独立消息组件使用相同来源。输入区不再改写描边或单独偏移某个 SVG。
双箭头展开控件保留已确认的图形，尺寸为 20px，描边为 1.75。

头像、品牌插图、二维码、图表、媒体覆盖层和复选框内部标记按各自组件的几何约束绘制，
不与普通操作图标强制同尺寸。进度环属于进度反馈，不作为线性操作图标处理。

验证覆盖 PC 1440×900、触屏布局 390×844，并抽查 320 / 768 / 1920px 宽度及暗色主题。
页面检查记录与截图位于 Social Web 的 `docs/web-icon-audit-2026-11-16.md`。
