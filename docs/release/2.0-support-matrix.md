# 2.0 Support Matrix

每个平台 2.0 声明支持什么、最低运行时是什么、本候选**实际验证到了哪一级**。声明与验证分列：声明来自包清单与 [../../COMPATIBILITY.md](../../COMPATIBILITY.md)，验证等级（L1–L6）定义见 [2.0-manual-evidence-checklist.md](2.0-manual-evidence-checklist.md) §1，逐条状态以 `artifacts/release-2.0/evidence-manifest.json` 为准。

## 1. 包与运行时

| 平台 | 包坐标 | 版本 | 最低运行时（声明） | 分发 |
|---|---|---|---|---|
| Vue（Web / Tauri） | `@flare-im/vue-ui` + `@flare-im/tokens` | 2.0.0-rc.1 | peer `vue ^3.5.42`、`naive-ui ^2.44.0`；browserslist Chrome 87 / Edge 88 / Firefox 78 / Safari 14 | npm，源码分发（`main: src/index.ts`），9 个显式入口 |

| SwiftUI | `FlareIMUI`（`packages/ios-im-ui`） | 2.0.0-rc.1 | iOS 16 / macOS 13 | SwiftPM 源码包 |

## 2. 验证到的等级（本候选）

| 平台 | L1 STATIC | L2 BUILD | L3 SIMULATED | L4 RUNTIME | L5 PHYSICAL_DEVICE | L6 PRODUCTION_LIKE |
|---|---|---|---|---|---|---|
| Vue kit | 设计系统门禁、安全边界、安全审计 | `vue-build`（vue-tsc + 191 个 SFC 编译） | vitest；axe；媒体仿真（reduced motion / forced colors） | clean consumer 在 Chromium 挂载与点击；`performance-budget` 真挂载 | 不适用 | `web-live-sdk`（真 Chromium + 真 web app + 真 SDK + 本地真服务端） |
| Web reference app | `reference-ownership`、`design-source` | `web-build` | `web-tests` | `web-browser`（Playwright） | 不适用 | `web-live-sdk` |
| Tauri app | — | `tauri-build`、`tauri-native`（cargo check） | `tauri-tests` | **NOT_RUN**（桌面运行时未启动过；`NATIVE-TAURI-RUNTIME`） | 不适用 | NOT_RUN |
| Flutter kit + app | analyze | `flutter-app-build`（macOS debug） | kit / app widget 测试（含 Semantics、手势 drag / longPress） | **NOT_RUN**（`NATIVE-FLUTTER-RUNTIME`） | NOT_RUN | NOT_RUN |
| Android kit + app | lint | `assembleRelease` / `assembleDebug` | JVM 单测；`compileDebugAndroidTestKotlin`（只编译，本机未跑 instrumented） | 模拟机 `Pixel_9_API_35` 对本地真服务端：收发 / 已读 / 前后台通过 | **BLOCKED_EXTERNAL_ENV**（无真机） | **FAIL**（`NATIVE-ANDROID-RUNTIME`：页头压状态栏、返回不可达、键盘遮发送、长按空菜单） |
| iOS kit + app | — | `ios-app-build`（generic iOS Simulator，免签名） | `swift test`（ViewInspector） | iPhone 17 Pro 模拟器对本地真服务端：收发 / 已读 / 返回 / 置顶通过 | **BLOCKED_EXTERNAL_ENV**（无真机） | **FAIL**（`NATIVE-IOS-RUNTIME`：ID 输入自动大写改写账号等） |

## 4. 平台能力（摘自 [platform-fallback-policy.md](platform-fallback-policy.md)）

| 能力 | Web | Tauri | Flutter | iOS | Android |
|---|---|---|---|---|---|
| filePicker / imagePicker | supported | supported | supported | supported | supported |
| share | fallback | unsupported | unsupported | unsupported | unsupported |
| nativeBack | false | false | 能力位在 Android 上为 true，宿主 `onNativeBack` 未实现 | false | 能力位 true，宿主 `onNativeBack` 未实现 |
| safeArea | supported | unsupported | 非桌面 | supported | supported |

`share` 与 `nativeBack` 的缺席由 `REL-UNSUPPORTED-SCOPE` 交发布负责人接受或否决；接受记录写在 `artifacts/release-2.0/signoff.json`。

## 5. 不在 2.0 范围内

- 通讯录 / 群目录（Social API，见 [../2.0-reference-app-feature-matrix.md](../2.0-reference-app-feature-matrix.md) 的 N/A 行）。
- SDK 重连与重复投递注入：属于 client SDK 行为，不是设计 kit 2.0 契约；`web-live-sdk` 报告在 `notCovered` 里列出。
- Tauri 深链与通知：不是 `spec/platform-contract.json` 里的能力。
