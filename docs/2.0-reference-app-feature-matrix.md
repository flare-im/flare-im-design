## Evidence And Boundaries

- Web and Tauri share `examples/shared/vue-reference/workbench`; their host factories use Web/WASM and Tauri IPC respectively.
- Native MessageRow adapters now use the public MessageBubble/MessageContentView path. Poll, task, calendar, mini-app and announcement content retain typed fields instead of generic placeholder summaries.
- Native poll/task default rendering is read-only. Voice/video now use public player chrome with platform decoding; file actions invoke SDK downloads. Real codec/protected-media/file completion verification remains incomplete.
- Flutter's bundled RTC stub advertises unavailable and rejects start. It must never pretend to create a working call.
- Contacts and group-directory are Social APIs, outside these Core examples. Their N/A status does not exempt library Contacts/Group components from release checks.
- Source-pattern ownership scans pass without suppression; the broader semantic audit still identifies native presentation fragments. Swift's unused composer controls were deleted and its live pack picker uses the public component. See `2.0-readiness-matrix.md`.
- Unit/build results and prior Web login checks do not prove all feature rows across all required mobile/desktop viewports. A candidate-specific interaction suite is still required.
- Actual production same-origin login passed. Current local sources, using the existing Vite proxy and real WSS service, passed bidirectional desktop/mobile text and history after refresh with isolated release accounts. The repeatable live SDK script is part of release:check; it does not certify media/offline/native/receipt-state flows. Earlier cross-origin OPTIONS failure was not a production outage; keep the configured gateway path prefix.
