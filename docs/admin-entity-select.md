# 管理端身份选择器

`@flare-im/vue-ui/admin` 的 `FlareAdminEntitySelect` 使用真实Naive `NSelect`，
不接业务API、不允许自由输入ID，不持有租户、权限或搜索缓存。

`FlareAdminEntityOption` 的 `value` 为不透明字符串，`label` 为完整可读身份；
可选 `title`／`description` 分别为姓名与账号。候选显示首字头像、姓名及账号两行；
已选标签只显示姓名，完整身份保留在title中。无结构化字段的通用选项保持原label。
头像仅是本地文字占位，不加载任意用户头像URL。文本插值，不使用HTML。

多选可启用 `selectionSummary`，宿主提供本地化的 `selectedText`、`manageText`、
`collapseText`、`clearText` 和 `removeText`。人数和操作位于输入框上方，避免被下拉覆盖；
管理时主动收起候选。展开的已选清单显示完整身份并可逐个移除，最大128px内滚动，
不把200个成员撑成无界表单。移除后焦点回到人数／操作区域，键盘可以接续。

上限到达时禁用新增候选；降低上限不会静默丢弃已有选择，仍允许只做移除。
不可用的已有选项只可保留或移除，不能借它引入未知ID。disabled同时约束选择、管理和移除。
加载、空结果、错误重试与分批加载沿用原交互。small按钮、语义tokens及移动端换行保持一致。

`clearable` 默认开启；必填选择可显式设为 `false`，隐藏清空入口并拒绝空选择事件。
它不改变已有选项的校验、单项移除或宿主的必填规则。

应用拥有搜索、防抖、分页、权限、范围隔离与业务数量约束。建群的群主预留名额／去重
留在Console适配层，不进入Kit。该新增组合仅用于Vue管理端，不改变原生通信客户端。

验证包括实际Naive组件的转义、紧凑标签、已选管理／关闭候选、零容量、超限移除及disabled；
宿主另验正常用户查询、权限撤回和应用切换。不能以组件通过替代群创建的后端验收。

`remote` 默认 `true`，搜索交由宿主；完整且有界的本地目录可设为 `false`，复用 Naive 的本地筛选，不需要让应用复制选择器。必填引用仍使用 `clearable=false`。
