# Web 媒体控件

语音试听复用 `FlareSlider`。非表单场景通过 `ariaLabel` 命名，并通过 `ariaValueText`
提供可读的时间（例如 `00:02 / 00:13`）。滑轨与圆点共享垂直中心；扩大触控高度时，
调整组件高度，不给原生 range 单独添加顶部内边距。WebKit 圆点按滑轨高度补偿，Firefox
使用原生居中规则。移动端试听保留 48px 的拖动区域。

`FlareCallView` 的 `localVideo` 插槽可能在异步摄像头采集之后才提供。每次渲染都应读取
插槽是否存在；不能把非响应式插槽集合的初始结果缓存进 computed。摄像头关闭后同步移除
预览与为预览预留的空间。

插件金额输入继续使用 `FlareInput` 的前缀插槽显示服务端币种，辅助技术的名称同时包含字段
标签与币种。所有金额输入和提交仍是十进制字符串；展示调整不参与资金计算。
