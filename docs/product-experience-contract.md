# 产品体验与交互契约

用于 Social / Core 示例应用以及后续 Web、Tauri、Flutter、Compose、SwiftUI 的体验对齐。视觉与状态的权威定义继续是 `tokens/tokens.json`、`spec/components.json` 和已有交互向量；本文约束组合方式，不创建另一套设计系统。

## 任务与信息层级

消息内容是首要信息；输入、恢复与当前会话上下文是第二层；时间、回执和低频管理动作提供辅助信息。品牌强调用于选中、行动与语义状态，避免让所有表面都成为强调色。使用现有文字、表面、间距、圆角、层级和动效 tokens。

桌面保留导航、列表、聊天和按需详情。平板优先保证可用聊天宽度，详情使用浮层或页面。手机使用列表、聊天、详情的单屏导航，聊天或二级页面显示时主底栏让位。布局应依据共享壳层的实际容器，不把窗口宽度当成第二套设备判据。

## 状态与责任

组件接收状态并发出意图，应用负责数据、权限和业务流程，SDK 负责消息身份、同步、排序及可靠性。

| 场景 | 必须保留的反馈与恢复 |
|---|---|
| 首次加载 | 有名称的加载状态；不同时显示误导的空数据结论 |
| 刷新失败 | 已有内容继续可读，说明内容可能未更新并提供重试 |
| 空列表/筛选为空 | 区分没有任何内容与当前筛选无结果，给出相应恢复动作 |
| 离线/重连 | 持续状态与可执行恢复；不清除文字、录音或已选附件 |
| 发送/上传 | 分别呈现上传与发送状态；已入库失败使用原消息重试，无入库结果则恢复输入 |
| 权限/插件不可用 | 用现有能力状态解释不可用，不展示虚假的可执行动作 |
| 破坏性操作 | 明确作用对象和范围，沿用共享确认与忙碌/错误状态 |

名单首次加载不能成为空白滚动区；已有行刷新时保留内容并标记忙碌。Vue 的加载 EmptyState 使用有名称的状态语义，整体绑定点按意图时仍是按钮，嵌套操作不激活外层。减少动态效果时加载环静态呈现，文案继续说明状态。

## 保留页面的生命周期

导航目的地可以保留挂载，以保存滚动、筛选、输入和选择。隐藏页面必须同时退出焦点导航、无障碍树以及当前输入事件的处理。

- `getClientRects()` 非空只表示仍有布局盒子，不能证明页面可见。共享上下文层应同时识别 `inert`、`hidden`、`aria-hidden` 和 CSS `visibility`。
- 被隐藏的聊天多选不能因另一页的 Escape 而丢失选择。
- Teleport 到全局容器的面板不继承页面的隐藏状态。应用组合层应将目的地 `active` 传给拥有这些面板的页面，并以它控制呈现。
- 暂停呈现不等于丢弃业务状态；返回页面仍保留选中的设置、查询或输入。
- 跨断点时只对当前任务改变呈现。隐藏桌面设置不能在手机上自动成为覆盖当前聊天的面板。

## 搜索工作区

搜索框、类型和时间条件固定在上方，结果区域独立滚动。页面使用 `SearchPanel` 的 page 布局并由宿主提供有界高度；inline 模式用于已有留白的组合面。Grid 使用 `minmax(0, 1fr)`，防止最小内容尺寸撑出窄侧栏。

Vue 保持原生搜索输入与结果按钮语义：

- 查询完成后，在输入框按 ↓ / ↑ 直达首项 / 末项。
- 结果间用 ↑ / ↓，Home / End 到首尾；第一项 ↑ 回到输入框；Enter 激活当前结果。
- Tab 与 Shift+Tab 仍走标准控件顺序，不能把键盘用户困在结果里。
- IME 输入、修饰键以及等待中的新查询不抢方向键，不误选旧结果。
- 非空搜索框的 Escape 保留清词行为；会话搜索空词或结果上的 Escape 返回聊天，取消时恢复有效入口焦点。
- 消息结果显示命中附近的两行摘要，完整原文保留在可及名称与提示中。联系人、群组仍使用紧凑单行副标题。
- 行和“查看更多”至少使用现有 44px 触控目标，并具有可见键盘焦点；图片/首字母头像不重复朗读结果名称。

`SearchResults.focusSearch` 是 Vue 的焦点意图，由 `SearchPanel` 消费。原生端遵循相同任务顺序，使用原生焦点和导航机制；本文不表示原生硬件键盘、读屏与触屏已通过验证。

## 联系人与成员选择

共享 `ContactList` 在 Vue 提供同样的 ↑ / ↓、Home / End 行焦点顺序，首行 ↑ 发出 `focusSearch`；宿主用 `focusFirst`、`focusLast` 和 `focusContact(id)` 将搜索、返回路径与列表衔接。导航只移动焦点，Enter / Space 才按原生按钮或复选框语义激活，行尾操作保持独立。资料的当前行与多选勾选是不同状态。

手机从资料返回时保留查询和滚动，并将焦点交回原联系人；若该结果已不存在则回到搜索框。桌面在列表旁显示资料，用 `activeId` 指明对应行。Flare ID 是可公开查询的唯一标识，与登录使用的账号分开表述，不引导用户用私有登录凭据搜索他人。

## 媒体预览

图片预览以内容名称或本地化图片名作为对话框名称，默认加载/失败/重试文案跟随语言；宿主显式文案仍优先。查看器使用既有 media.stage / media.onStage 语义颜色。粗指针与手机控件使用共享触控目标；窄屏允许工具分行，并为内容保留真实工具栏空间，不能裁掉下载或关闭。文件详情等内容面板应使用已有 showClose，提供显式退出，保留 Escape、平台返回和遮罩关闭。

## 验收与证据

可见改动需要实际浏览器与前后证据。最低矩阵为桌面、平板、手机、窄手机，以及浅色和深色。尺寸检查必须记录实际 CSS viewport；工具截图存在缩放时不能从显示图片推算行高。

检查内容包括：长中英文、emoji、空态、加载、失败、离线、重试、键盘、触控、筛选、焦点恢复、跨断点、草稿与选择保留、消息上下文定位。截图不能证明消息真实投递、权限正确或完整无障碍合规；fixture、真实服务和原生验证分别记录。

Social Web 的本轮任务与证据入口：`flare-social-examples/apps/flare-social-web-app/docs/product-experience-upgrade-2026-11-17.md`。后续每批继续记录问题、实现、回归及未验证项，不以接入组件库或构建成功代替体验验收。


## 录音权限与中断恢复（Web 本批契约）

- 捕获失败使用结构化原因，不匹配浏览器原始错误文本。NotAllowedError→权限拒绝；NotFoundError→无输入设备；NotReadableError→设备无法启动；NotSupportedError→运行环境不支持；未知原因保留通用反馈。跨平台适配器应映射同一恢复语义，而不暴露底层异常文本。
- 提示在当前语音面板持续可读；允许用户重试或返回键盘。权限失败不清除文字草稿、不发送消息、不制造试听或成功状态。录音取消/晚到的权限结果必须释放设备。
- 浏览器与系统权限不可由普通产品按钮绕过；文案说明在哪里允许并提供重试。设备缺失提示连接设备，不能归咎于权限。
- 手持设备使用按住说话、桌面使用开始/暂停；状态和保留语义一致，遵守实际输入区域宽度及触控目标，不按视口等比例缩放桌面交互。
- 真设备采集与合成媒体验收分开记录。仅API存在不等于实现支持；精简headless shell可能返回NotSupportedError，真实权限流程使用具备采集能力的浏览器。

## 插件权限管理的共享组件契约

- CorePluginConsentList由Core插件UI适配层组合Kit的EmptyState、StatusBanner、SettingsList和确认框；应用只提供SDK port、名称和本地化文案，不另建授权UI。
- 初始/port未就绪显示加载；读失败提供重试，不能伪装为空授权列表。port变化或卸载后忽略旧读取结果。
- 撤销必须等待实际成功。失败保留原授权和确认框，说明失败并允许重试/取消；成功才移除记录。刷新失败与撤销失败是不同状态，不能吞掉写入失败再刷新清除错误。
- 文字的错误恢复、手机/平板/桌面与明暗主题均要验证；受控SDK故障测试不能证明真实授权持久化或策略执法成功。

## 通话失败、最小化与命令恢复

- Kit 的单聊、群聊以同一 `state/statusDetail/recoveryText` 语义呈现失败；相同错误不重复朗读/显示。失败时媒体控制不可执行，关闭/挂断始终可达；群聊不遗漏恢复入口。
- 最小化 Dock 接收真实 state，不在失败/重连/呼叫阶段继续显示“通话中”的时长或成功脉冲。失败可展开查看或挂断；粗指针与窄屏使用48px共享触控目标，保留可见键盘焦点。
- 媒体生命周期与呈现分开：最小化/展开不能重新入会、重建远端流或丢失静音/设备状态。实际媒体连通必须核对远端 stream 及解码帧，截图与本地预览不能代替该证据。
- 结果不确定的接听/挂断由 Call SDK 使用原 commandId 和原 payload 有界恢复；200/600ms 两次等待，最多三次。仅处理公开的结果不确定/网络不确定类型以及临时HOST_RESOURCE_UNAVAILABLE / AUTH_PROVIDER_UNAVAILABLE，明确权限/成员/认证拒绝保持最终结果。账号切换或 dispose 不继续重试或刷新旧会话；取消接听不因晚到成功重新弹出通话。
- Core连接状态以 `onConnectionStatusChanged` / `connection://status` 为准，进入online才补同步，online阶段RTT/质量变化不重复读取。本文约束跨平台语义，不代表原生端或公网RTC已验收。

## 聊天工具菜单读取恢复

`useComposerMenu` 的 loading / ready / failed 与菜单内容分开。成功的空菜单是可用状态；读取失败继续关闭工具能力，不能恢复旧权限或以默认菜单猜测能力。应用用现有Kit StatusBanner呈现失败并重试，重试只读取菜单，不改文字草稿、引用或发送结果。旧会话请求和卸载后的晚结果不能覆盖当前状态。已有工具刷新期间不增加无必要的加载横条。


## 钱包概览与表单密度（Web 本批）

- 钱包卡片把名称与余额并排放在首行，资产/币种和状态在同一信息带换行，明细作为末行入口。保留服务端金额原文、币种、状态、行身份和全部命令，不按币种猜测或合并金额。长名称/金额允许换行，不裁掉数字。
- 概览最多突出一个已声明的 primary 行动，其它同级操作仍直接可见；danger、确认、表单和输入绑定不变。此视觉整理仅用于 wallet，资金流程中的提交/确认层级不变。
- 隐藏余额的开关公开 pressed 状态；钱包本地详情兜底也必须遵守该隐藏状态。切换到独立交易页面仍由该页面自己的展示契约负责。
- 紧凑与整行单选共用单一 Tab 停靠点；方向键跳过禁用项并循环选择，Home/End 到首尾，Tab 正常离开。未选中或当前值不可用时第一项可用选项接收焦点，不自动写入业务选择。IME 和系统修饰键不触发选择。
- 触控使用既有 48px 目标，竖排紧凑选择减少目标之间的额外空隙；表单组以业务字段标签命名。密度优化不能通过缩小触控目标或裁剪标签实现。
- 桌面个人页的默认内容使用既有资料详情组件，读取当前用户资料；编辑仍进入原有编辑器。取消回到可读资料，不提交草稿；手机保留原有导航栈。

已比对 SwiftUI/Compose/Flutter 的钱包实现与字段/动作语义；它们仍使用原有卡片布局，本批没有原生渲染验收，不能把 Web 的尺寸结果套用于原生。后续按同一信息层级适配，并单独记录动态字体、长金额、原生焦点与读屏证据。


## 表单计数与标签（Web 第十一批）

`FormField.counter` 是可选的提示信息，放在标签旁，不属于控件的可及名称。计数与帮助文字通过 `aria-describedby` 关联；校验失败时错误优先。更新计数不重建输入框，不丢失焦点或草稿。插件文本/多行文本与个人资料编辑器统一使用此能力；过滤器不显示无必要的计数。

计数占用标签行，不能代替填写规则、金额范围或错误反馈。标签允许换行，计数保持可读，触控目标不缩小。原生 FormField 仍保留原来的帮助/错误布局，本批没有原生端计数位置的运行验收。Web 已覆盖 1440/768/390/320px 明暗、标签点击聚焦、Unicode 计数、草稿及下一步可达。

## 登录设备与资料草稿（Web 第十三批）

- `FlareDeviceSessions` 稳定地将当前设备置顶，不修改调用方数组；当前设备不提供下线动作。设备说明中的平台、最近活跃与登录时间必须来自真实字段，不把创建时间当成活跃时间。未知平台保留原值，坏日期不生成假时间。
- 重复出现的行命令可以使用 `SceneList.actionAppearance="text"`；危险语义、禁用、忙碌与确认规则不变。行操作用 `aria-describedby` 关联所属行的名称与说明，视觉标签保持简短。轻量外观仍保留共享触控目标和键盘焦点。
- `FlareProfileEditor` 提供可选 `draft` / `update:draft`，数据形状为 `FlareProfileDraft { name, signature }`。未传入时仍支持组件内部编辑；宿主可以把草稿保留在内存中，跨页面卸载/重新挂载恢复。不由组件发请求或写存储。
- Social Web 页面返回、切换菜单和跨断点布局保留文字草稿；明确取消、保存成功或更换登录身份才清除。保存失败保留字段及未保存状态，允许重试。刷新/关闭后的持久化不在本批契约内。
- 字段未改变时禁用保存，Enter 同样不能提交；空白昵称、忙碌、原有长度限制和宿主既有提交规则继续生效。未保存状态使用克制的内联提示，不额外弹窗打断导航。

本批 Web 浏览器覆盖 1440/768/390/320px、浅深色、确认取消焦点、草稿往返与取消，以及受控保存失败。已比对 Compose/Flutter 设备列表的动作语义，尚未验证原生渲染；不把浏览器触屏模拟称为物理设备验收。原始记录位于产品体验工作区 `phase8/`。

## 红包与音视频（Web 第十四批，2026-11-18）

- `FlareRedPacketComposer.errorField` 可选值为 `FlareRedPacketField`（amount/count/greeting/recipient）或 form。字段错误只关联该字段；服务错误属于整个表单，不把金额错误标红。省略时保留原来的金额错误行为。`focusField(field)` 只聚焦可操作字段；busy/locked/不可用时不移动焦点。金额精度、IME、原命令结果未知时的锁定规则不变。
- 红包发送表单的弧形装饰使用 compact，当前 Web token 下72→20px；总额标签和数值同排。390px受控群聊同一表单415.8→347.8px，字段区仍211px；减少的是装饰与重复纵向间距，不减少信息或触控目标。详情页的弧形保持原规格。
- 宿主按照生产者声明校验金额、份数上下限与成员选择；空份数0不进入准备命令。错误后聚焦字段，网络/服务错误保留可编辑值。
- 自定义编辑器可以使用宿主页面栈提供的 `contentState` 保留未提交值。它只在当前导航帧的内存中存在；返回/刷新可恢复，关闭、重新打开、隐藏或更换会话身份时清除。不能存支付密码、授权凭证或命令结果。恢复成员必须重新匹配当前授权候选，恢复草稿不能发命令。
- 单聊视频五个控件在320px保持一排，目标至少44px；群聊六个控件在窄屏分为三列两排。保留语音/视频切换、设备选择、加人和挂断全部语义。来电身份和动作使用正常弹性流，适配768×375横屏；接听/拒接不被裁切。
- 语音失败状态的恢复按钮继承当前主题文字，具有可见焦点；不能在浅色面板上使用白字。菜单Escape只关闭菜单，最小化/恢复保留媒体流和静音状态。聊天头部入口使用原Call SDK的可用动作判断，权限、人数和配置不在UI层放宽。

Web已覆盖1440/768/390/320px明暗、字段与服务错误、来电横屏、真实两账号红包准备/授权拒绝/支付取消/已有领取详情和记录读取，以及真实麦克风/摄像头双端媒体。后者在同一台电脑的两个浏览器上下文运行，移动端指触屏视口；不等同于实体手机、公网RTC或原生客户端验收。对照过原生接口语义，本批没有原生渲染变更或实机结论。新红包扣款与领取未在本批执行。

## 红包记录列表（Web 第十五批）

单一行操作在窄容器中与记录同排，触控按钮至少44px高；多个动作及带标签的复杂记录仍保持纵向布局。行内容可以换行，不截断金额或状态。该规则落在通用插件列表中，页面继续使用同一列表组件、分页和动作。

Social Web 仅对红包发出/收到记录的既有五列投影转换显示：已知服务状态使用本地化文案，已领取数量带说明，仅在两个资产标识完全相同时去重；未知状态原样保留。转换不修改行键、详情输入、动作、原始数据或服务端状态。新增的中英文文案当前只覆盖Web；其余平台需要各自接入与运行验收，不将Web结果视为跨端完成。

来电接听后、媒体会话尚未创建时，宿主通过 `controlsDisabled` 暂时禁用麦克风、摄像头和设备控件；挂断仍可用。不能把尚无媒体会话的按钮画成可操作、吞掉静音点击，让用户误以为自己已经静音。媒体状态到达后恢复控件，显式静音仍由既有媒体会话执行；不会替用户改变默认音频策略。
