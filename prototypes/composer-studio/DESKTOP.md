# 桌面 Web 设计预览

最新浮层规则：表情、贴纸、@成员与语音统一紧贴输入框上方，左右边缘与整个输入框严格对齐。表情网格按宽度增加列数，成员搜索铺满可用宽度，录音区域保持居中。各面板高度仍由内容及可用空间决定，互斥切换，点击外部关闭；图片继续直接打开文件选择器，手机不变。浏览器验证左右边缘分别同为 76.4375 / 615.5625px，@与语音均采用 absolute 浮层，不撑高输入区。

表情/贴纸现以右侧浮层紧贴输入框上方展示，不参与底部排版；可切换页签、连续插入，点击聊天区或关闭按钮退出。浮层高度依照顶部剩余空间限制。Web 图片按钮直接触发多选图片文件选择器，不经过示例相册面板；手机保留原相册演示。浏览器已验证绝对定位的浮层底边与输入区顶边相距约 3px，并捕获图片点击触发的 filechooser 事件；没有上传文件。

最新调整：参照用户提供的 Web 输入截图，展开/收起、表情、@、语音、图片、格式、更多和发送组成右侧工具组。短消息同一行，长文/展开在右下角；不再显示工具组中间的快捷键文字，但 Ctrl/⌘ + Enter 仍可发送。手机不显示新增的桌面展开按钮，继续原有布局。已目视验证展开态并测量：工具组在 784px 宽操作行的最右侧，发送距离右边缘约 9px。

通过“手机 / 桌面 Web”切换布局，不创建新编辑器：草稿、回复、格式、附件、功能配置和权限策略共用。默认打开桌面版。

桌面采用应用导航、会话列表、聊天工作区；1500px 以上增加会话资料栏；1100px 以下收起演示说明面板；720px 以下隐藏静态会话列表并减少边距。导航、其他会话和资料栏为布局示意，当前交互会话仍为林小满。

输入区与聊天列同宽，普通态可容纳多行文字；展开只占当前聊天列，顶部保留部分聊天上下文，不覆盖会话列表。图标、格式与手机一致，底部工具靠左，发送和快捷键提示靠右。Enter 换行、Ctrl/⌘ + Enter 发送。更多功能优先单排展示，窄屏自动回到四列，保留动态配置与受限提示。

已在 1440 × 1000 浏览器视口检查普通与展开布局：聊天列宽约 828px、页面无横向溢出，格式栏完整可达。真实会话切换、通讯录导航、详情数据和文件上传未接入；本轮交付是桌面视觉与输入交互模型，不是完整 Web 客户端。

实现文件：desktop.css / desktop.js。现有 Vue/Flutter/原生生产组件未修改。
